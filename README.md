# CS-340 Client/Server Development

## Course Portfolio Reflection

### How do you write programs that are maintainable, readable, and adaptable?

Throughout this course, I learned the importance of writing code that is organized, reusable, and easy to understand. In Project One, I developed a CRUD Python module that allowed my program to create, read, update, and delete records in a MongoDB database. I was then able to reuse this module in Project Two to connect my dashboard to the database. This made the program easier to manage because the database operations were separated from the dashboard's interface. I learned that organizing code into reusable components makes it easier to troubleshoot, update, and expand a program. In the future, I could use a similar CRUD module in other applications that need to manage information stored in a database.

### How do you approach a problem as a computer scientist?

When working on the Grazioso Salvare project, I started by reviewing the client's requirements and determining how the database and dashboard needed to work together. The goal was to create an application that could help identify rescue dogs based on specific criteria. I approached the project by breaking it into smaller steps, including developing database operations, connecting the Python code to MongoDB, and creating an interactive dashboard with filtering, a data table, and a map. This project was different from some of my previous assignments because I had to connect several technologies to create one working application. I learned that testing each component and making adjustments along the way helps ensure the final program meets the client's needs.

### What do computer scientists do, and why does it matter?

Computer scientists use technology, programming, and problem-solving skills to create solutions that help people and organizations work more efficiently. Through this project, I learned how software can turn large amounts of data into useful information. The dashboard created for Grazioso Salvare allows users to filter animal shelter records and identify dogs that may be suitable for rescue training. Having this information organized in an interactive dashboard can save time and make the selection process easier. This project helped me understand how the skills I am learning can be applied to real-world situations and make a difference for organizations.
